# 收到或誤點後怎麼處理

依實際情況分流，避免把「收到訊息」與「已交出資料」混為一談。

| 狀況 | 下一步 |
| --- | --- |
| **只收到、未點擊** | 不回覆、不點連結或附件；從獨立官方管道查證。可使用郵件服務的檢舉功能，之後刪除可疑訊息。[S01](../sources/S01-ftc-overview.md) [S04](../sources/S04-google-gmail.md) |
| **已點擊，但未輸入資料** | 停止在該頁操作，不輸入密碼或驗證碼，改從已知官方網站或 App 查證。若懷疑下載了不明軟體，更新安全軟體並掃描裝置。[S01](../sources/S01-ftc-overview.md) [S04](../sources/S04-google-gmail.md) |
| **已輸入密碼、金融或個人資料** | 立即使用真正的官方網站／App 聯絡相應服務與金融機構，依外洩資料處理；在臺灣可撥 165 諮詢查證。若是帳戶密碼，從真正的登入頁變更密碼並檢查帳戶活動。[S01](../sources/S01-ftc-overview.md) [S04](../sources/S04-google-gmail.md) [S05](../sources/S05-acs-impersonation.md) |

## 回報的適用範圍

- Gmail 電腦版可在郵件「更多」選單選「回報為網路釣魚郵件」；其他郵件服務的操作方式不同。[S04](../sources/S04-google-gmail.md)
- 臺灣讀者若遇可疑詐騙簡訊或來電，可撥 165 諮詢。[S05](../sources/S05-acs-impersonation.md)
- FTC 提到的美國專用回報網站與簡訊轉寄號碼不直接當成臺灣通用管道。[S01](../sources/S01-ftc-overview.md)
