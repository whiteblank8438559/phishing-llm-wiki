# 案例：假冒資安機關的簡訊

資通安全署曾公開澄清：有人冒用相近機關名稱，假稱需要緊急下載資安防護元件，並附短網址。這是依官方公布案例整理的文字摘要，並非原始簡訊的逐字轉錄。[S05](../sources/S05-acs-impersonation.md)

## 將查證流程用在案例上

1. **暫停**：訊息要求「立即」下載，先不要點短網址或安裝軟體。[S05](../sources/S05-acs-impersonation.md)
2. **查看**：比對機關名稱是否被改字、訊息是否要求提供帳密或進行轉帳；這些都是警訊。[S05](../sources/S05-acs-impersonation.md)
3. **獨立查證**：自行尋找資通安全署官方資訊，或在臺灣撥 165；不依簡訊內的聯絡方式回覆。[S05](../sources/S05-acs-impersonation.md)
4. **回到一般規則**：這個案例有假冒機關、急迫語氣和短網址，但其他釣魚訊息未必具備完全相同的特徵。[S01](../sources/S01-ftc-overview.md) [S04](../sources/S04-google-gmail.md)
