# 可疑訊息的警訊

以下徵兆會提高風險，但**單一徵兆不能單獨證明訊息真偽**；仍須以獨立管道查證。[S01](../sources/S01-ftc-overview.md) [S04](../sources/S04-google-gmail.md)

1. **催促立刻行動**：例如聲稱帳戶即將停用、付款異常或安全元件必須馬上更新。[S01](../sources/S01-ftc-overview.md) [S05](../sources/S05-acs-impersonation.md)
2. **要求敏感資訊**：索取密碼、信用卡資料、銀行資訊或驗證碼。[S01](../sources/S01-ftc-overview.md) [S04](../sources/S04-google-gmail.md)
3. **要求點連結、下載或加入客服**：尤其是短網址、意外附件、陌生客服帳號或訊息內的付款頁。[S02](../sources/S02-npa-links.md) [S05](../sources/S05-acs-impersonation.md)
4. **冒用熟悉身分**：公司、政府、親友名稱與商標都可能被模仿；親友帳號也可能遭盜用。[S02](../sources/S02-npa-links.md) [S04](../sources/S04-google-gmail.md)
5. **網址或寄件資訊不一致**：顯示名稱和實際寄件地址、連結文字與實際目標，或網站名稱與真正網域不相符。[S03](../sources/S03-ntpc-url.md) [S04](../sources/S04-google-gmail.md)

警訊出現時，下一步不是憑直覺判定，而是照[點擊前的查證流程](verify-before-click.md)處理。
