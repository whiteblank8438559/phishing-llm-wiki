# S04｜Google：防範與回報釣魚郵件

- 發布者：Google Gmail 說明
- 原始資料：[防範及檢舉網路釣魚電子郵件](https://support.google.com/mail/answer/8253?hl=zh-Hant)
- 資料角色：釣魚定義、郵件檢查方法及 Gmail 的回報操作。

## 讀取後整理的重點

1. 網路釣魚可能透過電子郵件、訊息、廣告或仿冒網站，索取個資與財務資訊，也可能要求點擊連結或下載軟體。
2. 急迫語氣、好得不合理的好處、假冒熟人或機構，都可能促使人未查證就行動。
3. 檢查郵件時可比較寄件者顯示名稱與實際地址；在電腦上，點擊前可將滑鼠停在連結上，比較顯示網址與文字說明是否一致。
4. 即使已點開連結，若網頁要求輸入密碼，仍應停止，在自己知道的官方網址或 App 進行查證。
5. Gmail 電腦版可在郵件的「更多」選單選擇「回報為網路釣魚郵件」。

## 適用範圍與限制

「更多 → 回報為網路釣魚郵件」是 Gmail 的介面操作，其他郵件服務的按鈕名稱可能不同。寄件地址看似正常也不足以單獨證明安全。
