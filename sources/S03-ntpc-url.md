# S03｜新北市警局：假網址辨識

- 發布者：新北市政府警察局（文章引用臺灣事實查核中心的訪談）
- 原始資料：[假網址真詐騙！3 招教你辨認正確網址](https://www.police.ntpc.gov.tw/cp-3344-121607-1.html)
- 資料角色：網址混淆方式與回到真正官網核對的做法。

## 讀取後整理的重點

1. 隨機字串、外觀模仿官方名稱的網址都值得提高警覺，但網址外觀只能作為警訊，不能單憑是否有亂碼判定真偽。
2. 假網站可能把英文字母換成相似數字，或讓網址看起來含有 `gov.tw`，卻不是正確的政府網域。應看清實際網域，不只看訊息顯示的文字。
3. 無法確認活動、補助或服務是否真實時，應自己進入該機關或企業的官方網站查詢，而不是跟著社群或簡訊內的連結填寫資料。

## 適用範圍與限制

文章中的網址例子用來說明混淆手法，不能變成「所有亂碼網址都是假的」或「外觀正常就安全」的規則；真正的判斷仍要回到官方管道查證。
