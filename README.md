## 使用原則

- 主題頁以自己的話整理；重要判斷旁標示來源編號，再由來源筆記連回原始網頁。
- 臺灣的通報資訊與美國資料分開敘述；FTC 提到的美國通報管道不直接套用到臺灣。
- 當兩篇資料的例子不同時，保留共同原則：不要依訊息內的連結、電話或客服查證；改從已知的官方網站、App 或電話確認。
- 網站外觀、寄件者名稱或單一網址特徵都不能單獨證明安全；若不確定，先停止操作並查證。
